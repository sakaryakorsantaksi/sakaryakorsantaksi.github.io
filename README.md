# Sakarya Korsan Taksi

Sakarya korsan taksi yolcusu uçak için İstanbul'un Anadolu yakasına gider. Sabiha Gökçen Havalimanı Adapazarı'ndan 119 kilometre, 1 saat 17 dakika; Sapanca'dan 102 kilometredir. Otoyolda trafik saatine göre süre değiştiği için sürücü çıkış saatini uçuşa göre önerir.

Sapanca Gölü çevresindeki otel ve bungalovlara hafta sonu yoğun gidiş olur; orman içindeki tesislerin kapısına kadar çıkılır. Yazın Karasu ve Kocaali sahiline, sonbaharda Taraklı'nın tarihi evlerine gidilir. Kocaali 172 kilometreyle havalimanına en uzak ilçedir.
